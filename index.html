Projects

A selection of academic and personal projects I have worked on:

  1. Iskolar Alert: Incident Reporting & Lost and Found System

    Team Project | C#, ASP.NET Core, Entity Framework Core, Azure SQL Database, Bootstrap

    Developed a web-based incident reporting and lost & found management system for university use. Implemented async CRUD services with Entity Framework Core, advanced search with LINQ filtering, and secure file upload handling using GUID-based naming. Built authentication with BCrypt hashing, claims-based authorization, and role-based access control (Student/Admin).

  2. KwentoFlow

    Team Project | TypeScript, React, Node.js, Express, PDFKit

    Developed a web application integrating a lexical analyzer and parser with a React frontend and Express REST API. Implemented endpoints for real-time syntax analysis and transformed compiler outputs (tokens, AST, syntax errors) into structured JSON for visualization. Added PDF export functionality using PDFKit to generate downloadable analysis reports.

  3. PUPunta – Campus Route Finder

    Team Project | JavaScript, HTML5, CSS3, Dijkstra’s Algorithm

    Built a web-based navigation system for the PUP Sta. Mesa campus that calculates the shortest path between buildings and facilities. Implemented a custom Dijkstra’s algorithm with support for floor transitions, stair preferences, and penalty-based routing. Designed modular JavaScript components for graph modeling, node-edge relationships, and dynamic map visualization.

  4. Fake News Detector using Multihead Turing Machine

    Team Project | C#, Automata Theory, Rule-Based Text Analysis

    Designed and implemented a rule-based fake news detection system using a Multihead Turing Machine architecture to analyze short-form Facebook posts. The system processes text through three parallel detection heads analyzing emotional/lexical cues, structural punctuation patterns, and phrase repetition. Implemented deterministic state transitions and a weighted scoring model to classify posts as CREDIBLE or SUSPICIOUS, providing interpretable explanations and confidence scores for detected linguistic patterns.
